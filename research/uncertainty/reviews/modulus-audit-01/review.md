I reviewed the protocol, module, script, tests and the two completed records by hand, without executing anything.

## Identities that check out

**Dual signs.** Write rho_j = pilot + d_j and p = A1 pilot minus A0 pilot. The observation constraint gives w'(A1 d1 minus A0 d0) <= tau||w|| minus w'p for every w. Splitting ell'd1 minus ell'd0 through the adjoints yields ell'(d1 minus d0) <= B||ell minus A1*w|| + B||ell minus A0*w|| + tau||w|| minus w'p. That is exactly G(w) and the code's `B*residuals.sum()-w@p+tau*norm(w)`. Padded residual norms only enlarge G, so the reported upper stays a valid upper bound on the fixed-pair modulus. Weak duality suffices; strong duality is not needed for validity.

**Construction and scaling.** rho1 = pilot + a1 h1 and rho0 = pilot minus a0 h0 with a_j = B/upper(||h_j||) sit inside the ball. Feature gap a1(||ell||^2 minus w'A1 ell) + a0(||ell||^2 minus w'A0 ell) and mean difference p + a1(A1 ell minus A1A1*w) + a0(A0 ell minus A0A0*w) match the code's `target` and `action` terms. For lambda in [0,1], ||lambda rho minus pilot|| <= lambda B + (1 minus lambda)P <= B when P <= B, and the script asserts P = 1 while the module rejects B < P. Scaling multiplies both the image distance and the feature by lambda, which the code does.

**Testing threshold.** Whitened Gaussian means at distance D have minimum summed error 2Phi(minus D/2). The contradiction needs Phi(minus D/2) > alpha, that is D < 2 Phi^{-1}(1 minus alpha), so tau uses the 0.95 quantile and not 0.975. The 0.9999 factor makes the inequality strict. The deterministic-length restriction is what lets membership of the first feature bound the type II error by alpha; the argument extends only to lengths bounded almost surely by something below the gap. The script tests against `mean_distance_upper`, an upper bound on D, and 2Phi(minus D/2) is decreasing in D, so the recorded testing error is a lower bound on the true one. Correct direction.

**Phase-rotated Gram.** Translation multiplies each complex Fourier sample by a unit phase, which is a real orthogonal rotation of each (cos, sin) pair. matvec = R G R*, target = R A ell, action-error norm and coefficient absolute sums are invariant under R, and the preconditioner is conjugated consistently. The test's explicit matrix uses phase minus 2pi(k.x + t) with cosine and sine rows, which matches e^{minus i phi} = cos phi minus i sin phi and the base adjoint convention with isign = +1. Sign conventions do not affect validity of the lower bound because both signs of the pose are used and the pose ball is symmetric; they only matter for class comparison with the upper audit.

**Arithmetic on the records.** Both records are internally consistent to the digits shown:

The nominal case has p = 0, equal residuals and equal amplitudes, as identical operators require. In both records the unscaled feature exceeds the dual upper, which is not a contradiction because the unscaled pair violates the tau constraint. The scaled features are below the duals by the reported relative gaps. tau = 0.9999 times 2 times 1.64485 = 3.289378 and 2Phi(minus tau/2) = 0.10003 both reproduce. Module hashes are identical across the v1 and v2 records; only the script hash changed, consistent with the stated serialization-only fix.

## Issues

**T1. Silent clipping of an inconsistent residual square.** Severity: medium. Location: `two_pose_witness`, the `residuals.append(np.sqrt(max(0., ...)))` line. Unlike `continuous_residual_norm` in `uq_continuous.py`, which raises when the padded square is negative, this function clips to zero. A zero residual then gives amplitude B/tiny of order 1e307, the mean sum can overflow to inf, scale becomes 0 or nan, and the feature can become 0 times inf = nan. The only finiteness guard is on the CG iterate, not on the witness. A nan feature would fail the `>` comparison silently and the case would report the previous best without any error. Fix: raise when the padded square is below zero, and add `np.isfinite` checks on amplitude, distance, scale and feature before returning. Falsification test: pass a DenseGram with `target` returning a slightly wrong norm2 so the square is negative, and assert a raise rather than a returned record.

**T2. Integration-pad paths are never exercised by a test.** Severity: medium. Location: `tests/test_uq_two_pose_modulus.py`. `DenseGram.quadrature_error` returns zeros, so the tests cannot detect a wrong sign or wrong scale in `squared_field_norm`, `gram_action_norm`, or the way `two_pose_witness` combines them, and `PhaseRotatedGram.target`, `quadrature_error` and `preconditioner` are untested. The third test verifies the quadrature Gram against a matrix built from the same quadrature, so it also does not check that the pad covers the gap to the exact continuous Gram. Fix: build a tiny problem with a deliberately crude `QuadratureObservationGram` of order 3 or 4 so `kernel_error` is large, build the exact `ContinuousObservationGram` on the same frequencies, and assert that the exact ||A_j* w|| is at most `residual_norms_upper[j]` and the exact ||A1 rho1 minus A0 rho0|| is at most `mean_distance_upper`, for both scaled and unscaled witnesses. Also assert `PhaseRotatedGram(...).target` equals the explicit rotated matrix times ell.

**T3. The pilot-mean path is not tested against the nonlinear projection.** Severity: low. Location: `run_uq_two_pose_modulus.py`, the line `means.append(wrapped.rotate(cell_forward(k,...)))`. The protocol promises a comparison of the phase wrapper with constant-cell projections, but the tests only compare against an explicit Fourier matrix. `pose_cell_forward` in `uq_continuous_pose.py` computes the same quantity and would lock the sign convention. Fix: add `assert_allclose(wrapped.rotate(cell_forward(rotated_k,...)), pose_cell_forward(k,q,ctf,pilot,box,noise,pose,angle,shift))`.

**T4. Dual-upper weights and pair diagnostics are not saved.** Severity: low. Location: `optimize_two_pose_modulus` return value and the `np.savez` call. `best_weights` are the weights of the best feasible lower, while `dual_upper` is the minimum over all iterations and may come from a different iterate. In both shown records the last iterate achieved both, but that is not guaranteed. ||p|| is not recorded anywhere, although it determines whether the pose pair alone already separates the observations. The final history row lacks CG fields by construction, and the JSON does not record a hash of its npz companion. Fix: save the iteration index and weights of the best upper, store ||p|| and ||w|| in the witness, and hash the npz into the JSON. Falsification test: a case where the dual at the best-lower weights differs from `dual_upper` by more than the tolerance; assert the record exposes both.

**T5. Feature gap carries no downward floating-point pad.** Severity: low, already disclosed. Location: `two_pose_witness`, `feature=...`. Residual squares and the image distance are padded upward, but the reported gap is the plain floating value of a length 2n nq inner product. The lower bound therefore has real-arithmetic validity only up to unvalidated roundoff, as the `numerical_scope` field says. Since the dual-to-lower gaps are 0.2 to 0.5 percent and the roundoff scale is 1e-12, this cannot change any conclusion here, but a symmetric downward pad of the same 64 eps magnitude form would make the reporting uniform. No test needed; document in the protocol that the feature gap is unpadded.

**T6. Normalization of the relative half-width is unverified against the upper audit.** Severity: low. Location: `relative_half_width_lower=... /(2*fit['target_norm'])`. Dividing by twice the target norm is a convention that must match whatever the pose-aware upper widths divide by. Nothing in the packet shows that definition. If the conventions differ by the factor two, every lower-versus-upper comparison in the grid is off by that factor. Fix: import the same normalizer from the upper-width code or compare unnormalized half-widths.

**T7. Pose class identity between the two audits is asserted, not shown.** Severity: low. Location: `perturbed_geometry` and the `pose_set` field. The lower bound is valid for any class containing the two scaled pairs, so it remains valid for a superset class. It becomes uninformative for comparison if the upper audit's class is smaller, for instance separate rotation and translation balls with different radii, or a different radius scaling for the unit five-vector. The upper audit code shown uses the same row convention k @ exp(angle [u]_x) and the same `shift` scaling of q, which is consistent, but the joint-ball definition used by its spectral bound is not in the packet.

**T8. Whitening assumptions behind the threshold.** Severity: low, already disclosed. The 2Phi(minus D/2) formula needs identity covariance on the packed real and imaginary components after dividing by one scalar noise level. If the true covariance is not identity, for example through Friedel-related duplication or frequency-dependent noise, the correct distance is the Mahalanobis one and the recorded testing error is not a bound in either direction. This is the calibration gap the protocol declines to address; the lower bound is conditional on the declared noise model.

**T9. The v1 record was edited after the crash.** Severity: informational. The file in `two-pose-modulus/` contains `error`, `failure_log` and `failure_log_sha256` fields that the crashed script could not have written. The content is consistent with the trace, the pre-fit `save()` succeeding, and the v2 iterations reproducing the same four rows to all digits. The record should state that these fields were added by hand.

One interpretive remark. Under `coherent_x` every particle rotates the same way, so the class contains a near-global rotation of the density. That is a genuine ambiguity of the declared class, not an artefact, and the isotropic center target is nearly invariant to it while the z-contrast target is not. The larger contrast gap in the second record is therefore expected, and neither number says anything about tightness of the upper widths, as the protocol correctly states.
