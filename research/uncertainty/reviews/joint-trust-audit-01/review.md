I audited the packet as written, without running anything. Summary first: the core mathematics checks out. The robust-norm surrogate is convex, the residual-controlled inequality is a correct chain of weak duality plus an exact algebraic identity, the sign conventions in the witness, cuts and cross vector agree, the same-event minimization is legitimate, and the independent S-lemma and trust-region SDP tests are correctly assembled. I found no validity error in the bound. The findings below are robustness, bookkeeping, test-coverage and design-quality issues, plus a list of what the packet does not establish.

## Identities verified

- **Convexity.** For fixed v, ell minus A\*w minus F(w)v is affine in w since F is linear in w. A norm of an affine map is convex and a supremum of convex functions is convex. The bound by the triangle term follows from the triangle inequality.
- **Gram and cross accounting.** Expanding the squared norm gives H² plus v'G_cont v minus 2(F_cont\*h)'v. Replacing G_cont by G costs at most L² ε_G, and replacing F_cont\*h by b costs at most 2L ε_b by Cauchy–Schwarz on the ball. The implementation maps ε_G to the degree-6 kernel pad and ε_b to the cross pad, and does not substitute H for the cross error.
- **Completing the square.** With D = λI − G ≻ 0, v'Gv − 2b'v = λ‖v‖² − (v'Dv + 2b'v) ≤ λL² + b'D⁻¹b, since v'Dv + 2b'v ≥ −b'D⁻¹b at v = −D⁻¹b. Correct for any λ > λ_max(G).
- **Resolvent identity.** For r = b − Dx, r'D⁻¹r = b'D⁻¹b − 2b'x + x'Dx, so b'D⁻¹b = 2b'x − x'Dx + r'D⁻¹r for every x. The code computes Dx as λx − GQy using the stored images, so the identity needs only that the images are exact operator actions, not orthogonality or Lanczos structure. The bound r'D⁻¹r ≤ ‖r‖²/(λ−U) needs only λ_max(G) ≤ U and λ > U, both enforced. Clipping a negative value to zero is valid because the true quantity is nonnegative.
- **Witness signs.** Maximizing v'Gv − 2b'v on the ball is the trust-region problem with A = −G. The KKT solution is v = −(μI − G)⁻¹b with μ ≥ λ_max, matching v = −c/(gaps + shift). The returned direction has b'v ≤ 0, so both terms of the objective are nondecreasing under scaling to the boundary, which makes the post-failure boundary extension sound. The hard-case branch adds a top-eigenvector component to reach the boundary, and the analytic test value 5·4 + 1/3 is correct.
- **Cuts and cross vector.** The augmented cut matrix gives ‖(A\* + F(·)v)Qx − ell‖ = ‖h − Fv‖. The audit cross vector F\*ell − F_Q\*(A\*w)_Q equals F\*h up to the padded quadrature error. Signs are consistent throughout.
- **Same-event minimization.** For fixed weights and fixed U, every λ, x, the triangle value and the earlier joint/triangle bounds are deterministic functions, so taking their minimum costs no probability. The spectral event is drawn from the spatial Gram, whose nonzero spectrum equals that of G, so U bounds λ_max(G).
- **S-lemma SDP.** Applying the Schur complement to the unit-ball block yields, for all (s,u), ‖hs − fu‖² ≤ t²s² + tλ(‖u‖² − s²), which by the S-lemma with u = 0 strictly feasible is equivalent to sup_{‖u‖≤1}‖h − fu‖ ≤ t. The first unscaled attempt was also correct, just badly conditioned. The trust-region dual in the other test is the standard Schur form and strong duality holds for this problem class. The hard-case construction using the minimum eigenvector for b is valid because it is orthogonal to the top eigenvector and the unconstrained solution is well inside the ball.
- **Probability.** The threshold c = √2·erfinv(δ^{1/m}) is correct for m independent standard Gaussian coordinates, and the power bound holds simultaneously for all p on the one event. Splitting α into α−δ for noise and δ for the spectral event is a valid union bound.

## Findings

**T1. Medium. Audit aborts instead of falling back to the retained triangle bound.**
Location: `quadratic_dual_upper` and `resolvent_upper` in `src/fourier_splats/uq_trust_region.py`, called from `audit_joint_cubic`. The grid starts at log-shift −20, where λ−U is about 2×10⁻⁹ times the scale. If the Krylov space contains the leading eigenvector and U is tight, the reduced system is nearly singular. In floating point this can trigger a LinAlgError from `np.linalg.solve` or the FloatingPointError guard on a negative value. Either exception propagates out of the whole audit, after the design phase has consumed its budget, and the script then refuses to overwrite the failed output path. This is not a validity error, since the triangle value remains valid, but the code has a valid fallback it never uses. Fix: wrap each λ evaluation, record failures, skip them, and keep the minimum with the triangle bound. Test: feed a rank-complete basis with U equal to λ_max and check the routine returns the triangle value rather than raising.

**T2. Low. Selection minimizes a lower diagnostic, and the reported gap does not belong to the selected weights.**
Location: `design_joint_cubic` in `uq_joint_cubic_design.py`. The guide value at x is B times the larger of the Krylov witness norm and the best retained cut, both of which under-estimate the quadrature supremum. Choosing the evaluation with the smallest such value can prefer a point where the oracle was weakest, especially early when few cuts exist. Also, `gap` is computed from the current value, unlike `optimize_reduced_cubic` which uses the best value, and the returned `restricted_guide_gap` is the last record's gap, which need not refer to `selected_evaluation`. The final fresh audit makes this a design-efficacy issue only. Fix: after the loop, re-evaluate every checkpoint against the full final cut set before selecting, and report the gap for the selected evaluation. Test: construct a case where an early evaluation has a small guide value only because its cut set was small and verify the re-scored selection changes.

**T3. Low. Secular root tolerance is absolute in the dimensionless shift.**
Location: `dense_quadratic_witness`, the `brentq` call. `xtol=1e-14` is absolute, so a root near 10⁻⁹ is resolved to about five relative digits. That is the mechanism behind the retained first failure, and the boundary extension covers it correctly. The refinement is still a guide-quality loss in near-hard cases. Fix: solve in log δ, or set `xtol` to a small multiple of `low` and rely on `rtol`. Test: repeat the near-hard case without the boundary extension and check the value matches the SDP to 1e-10.

**T4. Low. Test coverage leaves the production path untested for tightness and independence.**
Location: `tests/test_uq_trust_region.py` and `tests/test_uq_joint_cubic_design.py`.
- The dual-versus-SDP test uses U exact to 10⁻¹⁰ and `steps=6` on a 6-dimensional problem, so the Krylov space is complete. Production uses 40 columns out of 7040 and a power-iteration U that may exceed λ_max by tens of percent. With loose U, the optimal λ may lie below U and the resolvent bound must sit above U with a residual penalty, so the resolvent value could exceed the old cross bound. Validity is unaffected because of the minimum, but usefulness is unverified. Add a test with U at 1.5×λ_max and `steps=3`, and record whether the resolvent value beats the triangle value.
- The robust-norm SDP test shares `pilot_root`, `remainder_roots` and `residual_coefficients` with the implementation. Independence is established only for the joint term. State this in the prerequisites record.
- The "covers direct sampled worst case" assertion compares a continuous bound including nonnegative pilot and quartic terms against a quadrature-order-4 guide, so it can pass with slack even if the joint term were wrong. Compare the joint term alone with those terms zeroed.
- With two starts, `krylov_cache` alternates chains, so the effective depth from b is about half the column count. This matches the protocol wording but should be recorded in the cache diagnostics.

**T5. Low. PSD pads inflate cut values and are reported as the guide norm.**
Location: `add_cut` and `witness` in `uq_joint_cubic_design.py`, and `psd_root` in `uq_cubic_subspace.py`. The pad is added to every diagonal entry of the augmented Gram, including the target entry, so each cut norm equals the true norm plus pad times (‖x‖² + 1). When an old cut beats the Krylov witness, `joint_norm_guide` is the padded value. This is ordinary floating point at the 10⁻¹³ relative level and is disclosed as a heuristic pad, but the master and guide are then compared on a slightly padded problem. Fix: report the unpadded norm alongside, or exclude the target entry from the pad, since only the weight block needs the guard for conic feasibility.

**T6. Low. Missing consistency guards in the joint routines.**
Location: `design_joint_cubic` and `audit_joint_cubic`. Unlike `optimize_reduced_cubic`, neither checks that `objective.z` equals the critical value implied by α−δ, nor that the seeds differ. The script passes consistent values, and the tests use the fixture's z, so nothing is wrong today. Additionally, `audit_joint_cubic` calls `objective.audit` with a zero support, which computes and then discards the old dual lower bound. That computation includes a raise if the discarded lower exceeds the upper. The derivation with zero support is valid, so the raise should not fire, but it is dead computation with a failure path. Fix: add the z and seed checks, and add a flag to skip the dual computation.

**T7. Low. Conservative relaxations worth stating explicitly.**
The cross-vector pad uses the degree-6 kernel error although the product of the density field and a cubic column has monomial degree at most 3. The reduced remainder majorant uses a per-column triangle inequality on amplitudes. Both are valid, disclosed as majorants, and only loosen the guide or the bound. No fix needed beyond a sentence in the theory note.

## What remains unverified

- The tensor Gauss kernel constant in `polynomial_kernel_error`, the eta majorant, the lifted-ball radius and the quartic remainder are inherited from earlier modules and are used here as premises. I did not re-derive them.
- Whether the resolvent bound is ever tighter than the retained cross and triangle bounds at production Krylov rank and realistic U looseness.
- Floating-point and NUFFT roundoff in the Krylov images, the reduced Gram symmetry defect, and the spectral power iteration, all disclosed as heuristic.
- Runtime feasibility of the design plus the audit inside the alarm.
- All experimental premises: normal noise, the density ball, the pose class and calibration. The protocol is prospective and carries no empirical result.
