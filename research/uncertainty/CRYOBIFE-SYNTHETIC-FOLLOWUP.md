# Cryo-BIFE: synthetic controls and supplement follow-up

1 October 2026 UTC. Read the remaining main-text synthetic-result and generation
sections, all seven supplementary text pages, and visually inspected all six

No author-code execution or fresh outcome is implied.

The synthetic studies vary SNR, defocus, particle count and path selection.
Supplementary controls compare posterior means with MAP and hard assignment,
and include a transporter with a nanodisc. Some high-energy regions show
visible disagreement with the reference despite narrower credible intervals;
a plotted realization is not a repeated-sampling coverage estimate. The
supplement specifies nuisance integration over orientation, displacement and
imaging parameters, so a baseline restricted to exact noise and known poses
would omit capabilities of this prior method. The synthetic data use Gaussian
noise and controlled viewing distributions; these experiments do not supply
coverage under arbitrary state-dependent preferred views or template error.

These results reinforce the need for a matched likelihood/population baseline
and an explicit target beyond simply adding posterior sampling. The earlier
reading record is historical; this follow-up supersedes its statement that
synthetic sections and the supplement had not yet been inspected. This is a
deeper reading of an existing ledger entry, not a new candidate count.
