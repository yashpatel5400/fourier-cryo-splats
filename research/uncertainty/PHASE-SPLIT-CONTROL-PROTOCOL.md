# Independent-image phase-alignment control

1 October 2026 UTC. A small diagnostic motivated by R9/R11, declared while the frozen cryo-EM end-to-end study is still running. It does not replace any of its 600 datasets or change their interval rules. Alignment attenuation, cross-validation and invariant moments are established prior art; this is an explicit coverage counterexample, not a novel reconstruction method.

For amplitude s=1, let A_i=s exp(i theta_i)+sigma Z_Ai and B_i=s exp(i theta_i)+sigma Z_Bi, where each real/imaginary noise coordinate is independent standard normal and theta_i is uniform. Fit theta_hat_i=arg(A_i). Compare: (1) known-phase oracle Gaussian intervals; (2) same-image aligned means with Student standard errors; (3) independent-image aligned means with the nominal measurement Gaussian SD; (4) independent-image aligned means with Student standard errors; (5) an unaligned cross-product amplitude interval obtained by inverting the finite-sample Bernstein bound in the accompanying derivation. This fifth procedure uses known noise; it is not experimental noise calibration.

Run exactly 2,000 independent datasets for each combination sigma in {2,1,.5,.25} and particle count in {16,64,256,1024,4096}. Use seed root 261003 and separate case identifiers. Keep the five methods paired within each dataset. Report coverage of s=1 with exact binomial 95% Monte Carlo intervals, signed bias, widths and empty intervals. Save all per-replicate endpoints/estimates and source hashes. Every failed interval counts as noncoverage. No parameter is selected from outcomes. This is a one-frequency phase model, not a cryo-EM reconstruction benchmark or proof about all alignment algorithms.
