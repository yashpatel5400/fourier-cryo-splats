# Reproduce the uncertainty development comparisons

These commands reproduce development studies, not an untouched confirmatory
benchmark. Start from the project environment, downloaded particle selections,
reference maps and metadata described in the repository README and provenance.
Install uncertainty dependencies and use the macOS FINUFFT build in COMPUTE.md.
Run from the repository root with its virtual environment active. The existing
scripts for splits, reference downloads, representation fits and initial audits
remain prerequisites; their recorded commands/configurations are in the result
files and development log.

```sh
export OPENBLAS_NUM_THREADS=4
pytest -q
for target in contrast center; do
  python scripts/benchmark_uq_ambient_pose.py --target "$target" \
    --quadratic-pose --gaussian-baselines --maxiter 500 \
    --output "ambient-quadratic-$target.json"
done
for reg in 0.001 0.01 0.1 1.0; do
  python scripts/benchmark_uq_group_bootstrap.py --replicates 1000 \
    --bootstrap 999 --regularization "$reg" --output "group-bootstrap-reg-$reg"
done
python scripts/audit_uq_grid_refinement.py
for target in center contrast; do
  for angle in 0.5 2.0; do
    python scripts/audit_uq_pose_grid.py --backend direct --target "$target" \
      --angle "$angle" --output "pose-grid-$target-$angle"
    python scripts/stress_uq_nonlinear_bias.py --steps 150 --restarts 4 \
      --source "pose-grid-$target-$angle" --output "nonlinear-stress-$target-$angle"
    python scripts/audit_uq_shared_density.py --source "pose-grid-$target-$angle" \
      --stress "nonlinear-stress-$target-$angle" --output "shared-density-$target-$angle"
  done
done
python scripts/summarize_uq_comparisons.py
python scripts/write_uq_results.py
python scripts/write_uq_citations.py
bash scripts/build_paper.sh
```

The source-group reconstruction runner, neural training/extension commands and
full checkpoint/evaluation records are under `group-reconstruction`,
`neural-reconstruction`, and `reconstruction-comparison`. Recreating MRCs and
weights requires executing the runs; large local arrays/checkpoints and
third-party source PDFs are intentionally not committed to Git. JSON records,
configuration files, FSC curves, bibliography metadata, figures and the PDF
are committed. The original acquisition and map hashes remain in provenance.

Computational availability is not scientific completion. Higher-bandwidth,
class-violation and fresh frozen studies are recorded separately as they finish.

## Continuous density and nonlinear pose audits

The continuous unknown belongs to the full unit cube L2 ball. The cube is a
broader support class than the finite-grid spherical-mask experiments; widths
are not interchangeable. Exact constant-cell generators are used only to
supply known simulation truths and pilots. Their cell sinc/phase factors are
part of the forward model. The new pose post-audit uses polynomial Fourier
fields and an explicit Gauss quadrature remainder; its weights were optimized
under fixed poses, so no joint optimum is claimed.

```sh
OPENBLAS_NUM_THREADS=4 python scripts/benchmark_uq_continuous.py --output continuous-optimized
OPENBLAS_NUM_THREADS=4 python scripts/benchmark_uq_continuous.py --backend quadrature --preconditioner-rank 1024 --output continuous-quadrature-optimized
OPENBLAS_NUM_THREADS=4 python scripts/benchmark_uq_continuous.py --backend quadrature --preconditioner-rank 1024 --particles 1024 --widths .07 --skip-exact-check --output continuous-quadrature-1024particles
OPENBLAS_NUM_THREADS=4 python scripts/audit_uq_continuous_pose.py
python scripts/summarize_uq_continuous.py
python scripts/summarize_uq_continuous_pose.py
```

`continuous_certificate` records both sum-objective bounds and CG diagnostics.
The pose audit records quadrature padding, feasible continuous-density stress
values and the no-data alternative. The source snapshot helper archives exact
executed bytes, including dirty development versions. Older development runs
precede this archiver; their partial hash records should not be mistaken for
complete immutable environments. A fresh final study must freeze code before
outcomes. Arrays ignored by Git are regenerated by the corresponding scripts.

## Frozen additional-exposure prediction component

The [protocol](confirmation/prediction-v1/PROTOCOL.md), selections and locked
model hashes were committed as `72a6dc0` before image access. This confirms
conditional experimental prediction on new exposure groups, not density
coverage or independently estimated poses. Do not retune on these outcomes.
After obtaining the exact frozen trained checkpoints, run:

```sh
for dataset in 10028 10049 10076; do
  python scripts/download_data.py "$dataset" --count 4096 \
    --indices-file "research/uncertainty/confirmation/prediction-v1/$dataset-indices.npy" \
    --output-directory "data/uncertainty/confirmation/prediction-v1/$dataset" --resume
done
OPENBLAS_NUM_THREADS=4 python scripts/evaluate_uq_fresh_prediction.py
```

The evaluator fails on checkpoint/selection drift. Source byte ranges and
checksums are public provenance; particle pixels are downloaded from the
original archive. Results retain all six prespecified paired method contrasts,
including their multiplicity-adjusted bootstrap intervals.
